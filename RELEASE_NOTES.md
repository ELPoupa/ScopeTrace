- Fixed: the exe could not start on its own on some PCs (missing WPF native libraries). It is now a true single-file exe.

Download `ScopeTrace.exe` below and run it, no install needed (64-bit Windows 10/11). The exe is not signed yet, so SmartScreen may show a warning the first time: click *More info* then *Run anyway*.

Features: live drawing of HP-GL screen plots from HP 54600 series scopes over RS-232, 1200 to 19200 baud, XON/XOFF or DTR handshake, CRT and paper themes, export to PNG, SVG or the original HP-GL file.
