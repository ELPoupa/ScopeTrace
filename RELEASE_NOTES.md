First release.

- Receives HP-GL screen plots from HP 54600 series scopes over RS-232 and draws them live
- 1200 to 19200 baud, XON/XOFF or DTR handshake
- CRT and paper themes
- Export to PNG, SVG or the original HP-GL file

Download `ScopeTrace.exe` below and run it, no install needed (64-bit Windows 10/11). The exe is not signed yet, so SmartScreen may show a warning the first time: click *More info* then *Run anyway*.
